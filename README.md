# GCore — Releases

Canale di distribuzione per l'auto-update dell'app GCore.

Contiene solo il manifest di aggiornamento e gli APK nelle Release.

- Manifest: [`releases/latest.json`](releases/latest.json)
- APK: sezione [Releases](../../releases)

## Formato manifest

```json
{
  "versionCode": 1,
  "versionName": "1.0.0",
  "url": "https://github.com/alyonhd-lgtm/gcore/releases/download/vX.Y.Z/GCore.apk",
  "changelog": "..."
}
```
